PREMIUM BIRTHDAY QR WEBSITE
============================

CUSTOMIZE:
1. Open script.js and change:
   const NAME="YOUR NAME";

2. Replace these photos:
   assets/photos/photo1.jpg
   assets/photos/photo2.jpg
   assets/photos/photo3.jpg
   assets/photos/special.jpg

3. Replace:
   assets/music/birthday.mp3

4. Edit the birthday text directly in index.html if you want.

FEATURES:
- 7 cinematic screens
- Smooth page transitions
- Interactive envelope
- Interactive gift box + celebration burst
- Photo polaroids
- Floating particles/stars
- Music toggle
- Mobile swipe navigation
- Keyboard arrow navigation
- Replay button
- Mobile-first responsive design

QR:
Upload the complete folder to a static web host. Use the final public
website URL to generate the QR code. The QR itself is not tied to the
files; it simply points to your public URL.

NOTE:
Most mobile browsers block autoplay. The music starts after the first
user tap, which is why the first button also starts the music.
